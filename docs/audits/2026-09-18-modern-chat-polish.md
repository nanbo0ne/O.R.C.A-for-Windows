# Modern 聊天界面精修验证

日期：2026-09-18。基线提交：`b86e04f8a9fdbb1bd5c6b27f2fa52289095420f7`。

本次只修改 V3 工作树内的聊天界面和相关测试，没有发布、修改安装版本或改动用户数据。Classic 以本次修改前的版本做对照；这不是对 Classic 与历史 V2 完全一致的新认证。

## 修改与原因

| 实际问题 | 原因和修改 |
| --- | --- |
| 少量回合的定位短线偏上 | Modern 定位条按内容高度居中，增加到 240px 后内部滚动，并限制为聊天区可用高度。 |
| 全屏输入框过宽 | 旧主题的 `max-width: none` 覆盖 Modern 限宽。排除该覆盖，正文、输入框及队列/审批共用 884px 内容宽度。滚动视口继续占满聊天面板。 |
| 运行文字挤在暂停与停止之间 | 底部改为左侧入口、中间弹性状态、右侧操作三个区域；长状态在自身范围省略。 |
| 模型与思考强度位置不对 | 右侧顺序为思考强度、模型、暂停/恢复、发送/停止。未声明强度的模型显示“模型默认”，提供现有供应商设置入口，不编造支持的等级。 |
| 控件厚重且拥挤 | 选择器默认透明，悬停、展开和键盘聚焦时有浅灰反馈。运行按钮为中性色，34px 点击槽位、约 30px 可见按钮面；极窄布局保留 30px 槽位。 |
| 左侧权限入口被隐藏 | 删除错误的 Modern 隐藏规则，保留左侧单个权限菜单；未修改 ask/auto/yolo 的业务语义。 |
| 窄窗口审批区域挤走正文 | 纵向排列时原 `flex-basis: 560px` 被当成高度。仅在 Modern 的对应断点设为 auto。 |
| 跳转旧回合后偏移约 6px | 恢复的历史消息播放位移动画，干扰定位测量。只停用 Modern 历史展开区域的入场动画，新消息及 Classic 不变。 |

模型与强度菜单补齐方向键、Home/End 和关闭后焦点恢复。Modern 使用系统字体和既有中文字体偏好，控件约 13px、常规字重 400；没有改系统 DPI、缩放或后端协议。

## 浏览器验证

测试使用真实 React 组件和 CSS、隔离的模拟后端。它验证渲染与交互，不代表模型服务或原生后端执行测试。

- 最终矩阵：362 个场景、3990 项断言、0 失败、38 张截图；无页面异常、控制台错误或外部请求。
- 窗口宽度：760 / 820 / 1024 / 1366 / 1920px；输入区宽度：320 / 380 / 460 / 580 / 720px。
- 覆盖中英文、两侧栏组合、空闲、运行、暂停、输入、取消、队列、审批、展开 Todo、长模型名与运行状态。
- 检查实际元素边界、控制行中心、稳定按钮尺寸、滚动视口宽度、菜单边界、键盘选项、取消及暂停/恢复的控制器调用。
- 少量回合定位条高度 70px，长会话上限 240px；鼠标、Enter 和 Space 定位检查通过。
- Classic 比较包含中英文、五种运行状态、三种窗口宽度及两种侧栏状态，共 60 组；每种分别对照修改前与当前 CSS 的几何和计算样式，结果零差异。另有相同 1920px 视口的完整前后截图。
- 合成图片及长文件名附件补测：五种输入区宽度，24 项断言通过，缩略图加载成功，底部控件继续单行对齐，无横向溢出。

中途一次 Classic 测试先丢失运行态，再因找不到暂停按钮而超时。核查发现测试存在挂载后回拨时钟及未等待控制器就绪的问题；已改为挂载前设置时钟，并等待实际订阅及历史恢复，额外断言对照前后的运行状态真实存在。旧日志不能唯一确认当次状态丢失的触发原因，没有放宽几何误差或隐藏产品错误。较早的失败记录保留，最终结果以以下 `full` 目录为准。

## 构建与原生窗口

- `npm run test:all`：通过，包含 streaming 回归。
- `npm run check:css`、`npm run test:ui-style`：通过。
- `npm run build`：通过。Vite 仍有现存的大块体积警告，不属于浏览器运行错误。
- 前端构建后执行 `wails build -s -skipbindings -m -nosyncgomod -o Orca-modern-review.exe`：通过。
- `git diff --check`：通过。

Windows Wails 使用无密钥隔离配置复核了 Modern 启动、最大化、右栏开关、居中和底部控件；Classic 独立窗口用于原生装饰及布局对照，之后已关闭。没有改动或关闭用户安装的 Orca 实例。原生运行中的模型调用未测，暂停/恢复/取消通过浏览器控制器模拟验证，不能互相替代。

一次隔离配置启动出现 `desktop-tabs.json` 原子替换 Access denied 提示；最终构建在相同配置重启后未再出现。原因未确认，本次没有修改迁移代码，也不把重启后消失写成已修复。随后额外的原生菜单操作遇到截图过期/窗口边界变化，未计为通过；菜单交互证据采用完整浏览器测试。

不含系统 DPI、真实供应商请求、安装升级或发布验证。
