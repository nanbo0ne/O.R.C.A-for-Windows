## 本轮修复

### 审批等待不再消耗网页执行时限

过去五分钟是从任务开始连续计时，用户看审批弹窗也算执行时间。现在由宿主
Controller 的真实审批/Ask 调用暂停任务时钟，批准或回答后恢复；模型不能通过参数
自行暂停时钟。嵌套等待只记一次，取消和外层截止时间仍有效。等待额度先持久化，
保存失败就取消后续执行；崩溃或重启不会凭空补出等待时间。十次生成、三十次工具动作
等边界不变。这是修复等待计时，不是取消权限或防重放。

### 恢复历史显示真实工具结果

工具成功、失败、取消作为显示元数据与工具消息一起保存，不改变发给模型的协议。
重开会话可以还原真实状态；旧历史缺失结果显示已停止，不再假装成功。成功读取的文本
即使含 `Error:` 也不会因内容被误判失败。旧会话只有确实缺少元数据时才用保守兼容。
这不等于所有请求级错误横幅都已解决；未知网页片段仍列为待处理。

### 账号登录缺少服务端接口时明确失败

本轮只发送了不带凭据、Cookie、用户内容的只读 HTTP 请求。当前
`https://sub.aichat.diy/api/v1/desktop/session` 返回 404；router 对应路径也返回 404；
公开 OIDC discovery 路径返回 HTML，而非预期 JSON。只能确认当前路径没有满足客户端
合同，不能据此推断服务器内部实现或扣费正确。

登录前增加八秒有界探测；缺少接口时不打开一个注定等回跳超时的登录流程，而是说明
“服务尚未提供桌面登录接口”，其它模型源继续独立可用。401 仅表示未认证路由存在，
不代表登录、模型列表或结算成功。旧 `account30` 服务端候选不能覆盖已经更换的现网。

### Controller 使用同一配置快照

桌面先前读一次配置来准备运行时，boot 随后再读一次。现在在 boot 完成迁移和加载后
通过内部回调准备运行时，模型和信任开关使用同一份配置。取消或准备失败直接退出；
托管本地 AI 和整机操控的禁用边界不变。

## 集中暂挂清单

1. **当前账号服务器合同与源码**：需要确认现在实际运行的身份/路由/账本版本及其桌面
   接口。已有匿名 404 证据和客户端隔离测试。下一步是基于当前服务做增量适配与隔离验收，
   之后才兼容部署；不需要用户现在重复点登录。不能将执行名额释放当退款，不能擅改资金规则。
2. **本人登录与真实结算**：上一项就绪后一次集中安排系统浏览器登录、回跳、模型权限、
   余额与请求 ID 对账。密码/验证码由本人输入。核价后遵守最多 80 次、人民币 5 元的付费限制。
3. **网页稳定性与复杂任务**：11 月 13 日真实主界面已有代码、CSV、跨文件、精确文本、
   问答和取消后的续问证据，部分依赖纠错或显式继续。不能宣称三次稳定通过。本轮未重跑真实
   DeepSeek；下一步在新候选上补齐三组各三题、原始片段变体和安全交接，不清除旧调用账本。
4. **浏览器真实 Agent 矩阵**：当前原生点击和 Go 回归不是模型操作全矩阵。继续合成页面的
   实际委派任务，独立核验页面提交结果、附件和取消，不由测试脚本代替模型决策。
5. **安装与并存**：需要无个人资料的可回滚 Windows 虚拟机。现有脚本拒绝直接用主机账户
   做安装/卸载验收，防止真实 shell 文件夹、快捷方式和 HKCU 受到环境变量隔离假象影响。
   没有通过这一步前不生成声称完整验收的安装器。
