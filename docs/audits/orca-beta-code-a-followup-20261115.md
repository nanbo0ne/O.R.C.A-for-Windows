### 工具结果自动回传的准确边界

正常流程是 Agent 保存工具结果，下一次模型请求由 V3 运输层把调用 ID、工具名称和
真实结果自动序列化到网页；无需人工粘贴。CSV 的多轮结果和最终答复已证明该流程在此例实际运行。

重要纠正：调用账本 `returned` 在 `acknowledgeResultsLocked` 中、**网页发送前**写入，
只证明宿主适配器收到匹配的工具结果，不能单独证明网页已收到、更不能证明模型已处理。
因此不得把 code-b 八项 returned 说成八项均已被网页确认。其最后一次结果送达和最终
生成中断仍需进一步区分；当前网页绑定已归档、无 inflight，不应盲目重发写入。

两题连续在 5 分钟处结束，说明当前多轮时限与收尾体验仍未达到完整验收要求。
未放宽上限，也未把不完整回合算作通过。需补充结果送达状态和超时收尾的针对性回归。
