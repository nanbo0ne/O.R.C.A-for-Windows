# O.R.C.A. Desktop 3.0.13

## English

This release keeps the existing conversation records available to review after context is condensed; it does not restore content that was already missing. Context-usage reporting is clearer, and the live work overview, guidance, attachment handling, paste behavior, and permission menu are improved.

- Existing messages remain visible in the conversation after context compaction; this cannot recover records that were already missing. Summary markers distinguish condensed context from the retained conversation.
- Guidance bubbles preserve attached images. Pasting the same image no longer adds it twice.
- The compact permission menu fits smaller windows, and the hoverable work-progress strip has been refined. It shows observed activity, not a complete event log; sensitive details may be omitted.
- Context-usage reporting and image/file attachment handling are improved.

See the [verification record](https://github.com/nanbo0ne/O.R.C.A-for-Windows/blob/desktop-v3.0.13/docs/audits/desktop-v3.0.13-verification.md) for platform builds, upgrade checks, signatures, package integrity, and deployment evidence. No production model requests or native-window testing on a user's personal computer are part of release checks.

The Windows installer is unsigned; macOS is not notarized. Minisign verifies update integrity only; it is not an operating-system publisher signature.

## 简体中文

整理上下文后，仍可查看会话中已有的记录；这不能找回此前已经缺失的内容。上下文用量显示更清楚，实时工作进度概览、引导提示、附件处理、粘贴体验和权限菜单也得到改进。

- 上下文压缩后，会话中已有的消息仍可查看；不会恢复原本就缺失的记录。摘要标记与保留的对话可区分。
- 引导气泡会保留附带图片；重复粘贴同一图片不再添加两次。
- 紧凑权限菜单适配较小窗口，悬停可见的工作进度条也经过改进。它只展示实际观察到的活动，不是完整事件记录，部分敏感详情可能省略。
- 改进上下文用量显示及图片/文件附件处理。

平台构建、升级、签名、包完整性及部署证据见[验收记录](https://github.com/nanbo0ne/O.R.C.A-for-Windows/blob/desktop-v3.0.13/docs/audits/desktop-v3.0.13-verification.md)。发布检查不会发送生产模型请求，也不在用户个人电脑上进行原生窗口测试。

Windows 安装器未签名；macOS 未公证。Minisign 仅验证更新完整性，不是操作系统发布者签名。
