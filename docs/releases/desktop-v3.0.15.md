# O.R.C.A. v3.0.15

发布时间：2026-11-22

## 新增

- **用鲸栈账号登录即可拿到中转模型访问。** 设置 →「供应商接入」顶部新增「鲸栈账号」卡片：填入鲸栈的用户名（或已验证邮箱）和密码，登录成功后自动出现名为「鲸栈」的供应商，Base URL 指向 `https://router.aichat.diy/v1`，模型列表按账号实际权限载入，无需手动填写 Base URL 或 API Key。
- 中转 Key 由统一登录服务按账号派生，同一账号在任意机器重新登录拿到的都是同一把 Key，不会在账号下堆积重复 Key。Key 保存在全局凭据文件的 `WHALESTACK_API_KEY` 中。
- 登录失败时（密码错误、账号未开通模型权限、服务繁忙）在卡片内直接给出原因；重新登录会复用已有供应商，不会重复添加。

## 修复

- Linux 上 `internal/sandbox` 的两个测试仍按「非 macOS 永不加沙箱」断言，而 3.0.0 起 Linux 已支持 bubblewrap，导致发布流程的守护任务一直失败。测试改为按 `bwrap` 是否在 PATH 上判断实际行为。

## 升级说明

- 覆盖安装即可，会话历史、配置与已有供应商不受影响。
- 鲸栈登录依赖 `login.aichat.diy` 与 `router.aichat.diy` 两个服务，两者均需可访问。
